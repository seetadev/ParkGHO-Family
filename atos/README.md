# ATOS — Autonomous Token Orchestration System

A decentralized multi-agent platform that orchestrates an ERC-20 token lifecycle across Filecoin and Ethereum using libp2p networking, IPLD data composability, and post-quantum cryptography.

Built for C4GT in collaboration with Libp2p (Protocol Labs), Multiformats, IPLD, NSUT × SEETA × AIC.

---

## Architecture Overview

```
Citizens / Operators
        │
        ▼
┌─────────────────────────────────────────────────────┐
│              libp2p Agent Network                   │
│                                                     │
│  Deployer ── Monitor ── Liquidity ── Governance ── Analytics  │
│       │           │          │            │              │    │
│       └───────────┴──────────┴────────────┴──────────────┘   │
│                        GossipSub pubsub                      │
│                     Kademlia DHT + mDNS                      │
└─────────────────────────────────────────────────────┘
        │                               │
        ▼                               ▼
Smart Contracts                  IPLD Block Store
(Sepolia + Filecoin)             (CID-linked logs)
        │
        ▼
Uniswap v3 Pool
(ATOS / WETH)
```

## Setup

### Prerequisites

- Node.js 20+
- Docker + Docker Compose
- MetaMask wallet funded with Sepolia ETH and Filecoin Calibration tFIL
- Infura account (free tier works)
- Etherscan API key (free tier works)

### Install

```bash
git clone https://github.com/your-org/atos
cd atos
npm install
```

### Configure environment

```bash
cp .env.example .env
```

Open `.env` and fill in:

```
PRIVATE_KEY=your_wallet_private_key
INFURA_API_KEY=your_infura_key
ETHERSCAN_API_KEY=your_etherscan_key
```

## Usage

### 1. Compile contracts

```bash
npx hardhat compile
```

### 2. Run tests

```bash
npx hardhat test
```

All 30+ tests must pass before deploying.

### 3. Deploy to local hardhat node (development)

```bash
# Terminal 1
npx hardhat node

# Terminal 2
npx hardhat run scripts/deploy.ts --network localhost
```

### 4. Deploy to Sepolia testnet

```bash
npx hardhat run scripts/deploy.ts --network sepolia
```

### 5. Deploy to Filecoin Calibration testnet

```bash
npx hardhat run scripts/deploy.ts --network filecoinCalibration
```

### 6. Verify contracts on block explorers

```bash
# Etherscan (Sepolia)
npx hardhat run scripts/verify.ts --network sepolia
```

### 7. Generate CEX listing artifacts

```bash
npx hardhat run scripts/cex-metadata.ts --network sepolia
```

Creates `cex-artifacts/token-metadata.json`, `compliance.json`, and `report.json`.

### 8. Start all agents

```bash
docker-compose up --build
```

This starts:
- Hardhat local node on port 8545
- Deployer agent on port 9001
- Liquidity Manager agent on port 9002
- Monitor agent on port 9003
- Governance agent on port 9004
- Analytics agent on port 9005

### 9. Open the dashboard

```bash
open dashboard/index.html
```

## IPLD Data Model

Every record in the system is content-addressed by a CID. Records link to each other by CID, forming a verifiable DAG.

```
AgentIdentity (CID = agent's identity)
        │
        ▼
TaskNode ──dependencyCIDs──► TaskNode ──► TaskNode
        │
        ▼
ExecutionLog ──previousLogCID──► ExecutionLog ──► ExecutionLog
        │                         (chain: oldest → newest)
        ▼
    result CID
```

All encoding uses dag-cbor + sha2-256. All cross-references are CIDv1 (base58btc).

## Post-Quantum Cryptography

The `pqc/pqc.ts` module implements a hybrid key exchange prototype:

- **Classical**: X25519 ECDH
- **PQC**: Kyber-768 KEM (NIST selected, lattice-based)
- **Combined**: `HKDF(X25519_shared || Kyber_shared)` → 32-byte session key
- **Encryption**: AES-256-GCM using the derived session key

This is a prototype. The Kyber functions are stubbed — replace with real `liboqs` Node.js bindings for production:

```bash
npm install @open-quantum-safe/liboqs-node
```

Then swap the stub functions in `pqc/pqc.ts` with:

```typescript
import { KEM } from '@open-quantum-safe/liboqs-node';
const kyber = new KEM('Kyber768');
const { publicKey, secretKey } = kyber.generateKeyPair();
const { ciphertext, sharedSecret } = kyber.encapsulate(publicKey);
const shared = kyber.decapsulate(ciphertext, secretKey);
```

## CEX Listing Preparation

Run `scripts/cex-metadata.ts` to generate the three required artifacts. Then:

1. Fill in all `FILL IN` fields in `cex-artifacts/compliance.json`
2. Complete a smart contract audit (recommended: OpenZeppelin, Certik, or Trail of Bits)
3. Deploy to mainnet and update contract addresses
4. Pin `token-metadata.json` to IPFS via web3.storage
5. Call `setMetadataCID()` on the deployed contract with the pinned CID
6. Submit to CoinGecko and CoinMarketCap first (required by most CEXs)
